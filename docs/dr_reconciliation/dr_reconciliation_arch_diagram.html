DR Reconciliation — Detailed Architecture

Recon engine + AI/BI dashboard over Databricks Managed DR · AWS · two-region
primary region (writable) secondary region (read-only) recon engine & dashboard monitor workspace Managed DR replication
1
Resolve scope
DR REST API + system.replication.states → in-scope catalogs, workspace sets, RPO target, blocking errors.
2
Read primary
Primary-side signature for every in-scope object of the 10 types.
3
Read secondary
Same reads against the read-only secondary via the monitor workspace.
4
Diff & classify
Compare signatures; fold in DR errors + silent-gap set → status + severity + readiness.
5
Persist
Idempotent MERGE into the four dr_recon_* tables.
6
Publish
AI/BI dashboard reads the tables via a SQL warehouse; alerts fire on regression.
↺
Failover / failback
Direction is read from effective_primary_region; the engine reconciles whichever region is primary, and logs each DR event + post-event reconciliation.
